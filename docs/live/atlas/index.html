How the API works

A drawable HTML subtree gives the browser a source to paint. The canvas can draw that paint directly, use it as a GPU texture, or capture a transferable ElementImage. DOM geometry connects the drawing back to pointer interaction and accessibility bounds.

Support varies by browser and graphics adapter. These examples probe each feature independently. The proposal also limits readback of information such as cross-origin content, uncommitted autofill, and visited-link state.
